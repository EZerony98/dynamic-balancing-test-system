# 动平衡测试系统

基于 PySide6、NumPy、pyqtgraph、LabJack LJM 和 NI-DAQmx 的双路振动动平衡测试上位机。左右输入可分别设置为压电陶瓷、IEPE 加速度传感器或未安装。压电模式只用 LabJack T7；任一侧选择 IEPE 时自动同时启用 NI-9234 与 LabJack FIO3。生产程序不提供运行时仿真、模拟设备或模拟数据入口。

## 接线与物理量

压电与转速信号接 LabJack T7；IEPE 加速度传感器接 NI-9234：

| 信号 | T7 接口 | 当前用途 |
| --- | --- | --- |
| 左侧振动传感器调理后电压输出 | `AIN0` + `GND` | 左路原始电压、FFT、候选 1X |
| 右侧振动传感器调理后电压输出 | `AIN3` + `GND` | 右路原始电压、FFT、候选 1X |
| 转子光电信号 | `FIO3` + `GND` | 转子转频与同步角参考；当前物理 PPR=1 |
| 左 IEPE 加速度（选择时） | NI-9234 `ai0` | 左加速度、FFT、1X 幅值 |
| 右 IEPE 加速度（选择时） | NI-9234 `ai1` | 右加速度、FFT、1X 幅值 |

同一 AIN 的螺丝端子和 DB37 接点属于同一通道，不要同时接入不同信号。接线前确认放大板输出范围、极性和公共端，避免超过 T7 模拟输入量程；不要把传感器 24 V 供电接到 AIN 或 FIO。`AIN3` 是右压电模拟输入，`FIO3` 是转子光电数字输入，二者不是同一个接口。FIO3 光电为 NPN 输出时，需确认它没有被外部上拉到 24 V。

未知放大板比例时，压电侧只以 mV 显示。在“系统设置 → 左右传感器”选择 IEPE 加速度后，程序自动通过 NI-9234 提供 2.0 mA 激励；PCB 353B15 默认先填写标称 10 mV/g，正式测量应改成校准证书值。IEPE 传感器不要直接接现有压电放大板或 T7 AIN。

单个加速度传感器测试时，将安装侧设为“IEPE 加速度传感器（NI-9234）”，另一侧设为“未安装”。未安装侧不参与饱和、SNR、1X 有效性或 QC 判定。NI 与 LabJack 没有共用硬件采样时钟，因此可输出转速和单侧 1X 幅值，但不冒充输出相对 FIO3 的绝对转子角。

## 生产测量流程

“生产测量”和“频谱诊断”已合并到同一个实时测量界面：

1. 输入或扫描工件编号（可留空），点击“开始测量”或按 `F3`。
2. 两侧均为压电时，T7 以一条 stream 按 `AIN0/AIN3/DIO3` 顺序同步读取；选择 IEPE 时，NI-9234 读取加速度，LabJack 同时保留 FIO3 转速及仍为压电的另一侧。
3. 界面同时显示左右实时波形、左右完整 FFT、转速、两路总 AC RMS、候选 1X 幅值、同步角和质量状态。原来单独显示的两张拟合正弦图不再占用主界面，避免与 FFT 诊断重复；相同结果仍以数值和状态保留。
4. 结果有效后点击“保存 2.0 秒数据”。程序从下一块真实采样开始精确截取 2 秒，末块按目标样本数裁齐并自动停止，不再由人工停止时间决定文件长度。记录包含左右传感器电压、FIO3 状态、FFT、转速快照和候选 1X；导出始终保留 V 原始列，加速度侧另给出 g 与 m/s²，压电侧另给出 mV。所有 CSV 文件名都以工件编号开头（未填写时使用 `NO_PRODUCT_ID`），记录目录还会生成同名前缀的 `field_dictionary.csv`，逐项说明字段、单位和计算来源。工件编号、左右传感器配置、灵敏度、采集后端及同步状态会写入元数据。
5. 实时测量页每侧同时显示原始波形、完整 FFT 和按候选 1X 拟合的正弦分量。两只 IEPE 同接 NI-9234 时可比较左右相对相位；由于 FIO3 仍由 LabJack 采集，不输出相对光电零位的绝对转子角。
6. 点击“停止”或按 `Delete` 安全停止本次测量。

左侧其它生产功能保留为独立页面：

- “双面动平衡”读取当前真实同步 1X 矢量，以极坐标显示左右幅值和同步角；未标定时不生成修正量。
- “试重标定”按无试重、左面试重、右面试重、校正后复测记录真实结果，可保存标定草稿；影响系数公式确认前不自动求解。
- “测量模板与 QC”把目标转速、稳定容差、平均次数和左右 mV 限值保存到本机；实时测量页可选择模板并给出合格、不合格或阈值待设置状态。
- “测试记录”读取真实记录/导出目录；“系统设置”显示实际接口并打开同一套 1X 参数；“系统日志”读取真实日志文件。
- “用户与权限”当前只保存本机操作员身份并展示角色矩阵。密码哈希、登录锁定和服务端权限尚未接入，因此不会把显示的角色误当成安全控制。

实时 FFT 默认显示到 300 Hz，可在界面修改；显示时长默认 0.2 秒，可调到 5 秒。这两个显示设置不改变实际采样率。

## 转速与 1X 逻辑

- 光电物理含义为每转一次，所以 `PPR=1`。现场 FIO3 读数约为预期转频的 4 倍，因此驱动层用独立的 `optical_frequency_divisor=4` 修正，再按 `RPM = 修正频率 × 60 ÷ PPR` 换算。界面同时显示原始、修正和平滑频率，便于复核。
- LV-N11N 转子光电默认使用 FIO3 连续下降沿测频。程序优先从左右联合谱选择最接近参考转频的可信局部峰；局部峰门限未通过时仍按光电转频直接提取并显示诊断预览，但不会误标为有效 1X。手动频率模式只用于观察。
- 单次转频跳变先保持旧值，连续多次确认后才接受新转速。完整分析窗内还会检查转速波动、异常保持比例、峰频偏差、SNR、输入饱和、丢样和同步边沿质量。质量不足时仍可显示候选峰预览，但不会把它标为有效 1X。
- “右相对左电气相位”只比较同一采样时钟下的两路响应。纯 LabJack 时 `A/B 同步角` 以同流采样的 FIO3 下降沿为 0°；NI/LabJack 混合通道会禁用左右相位，NI 与 FIO3 也不会输出伪绝对角。它们都不是已经标定的配重角。

## 标定与动平衡量

当前可靠输出是两路 1X 电压幅值、相对相位和光电同步角。未完成双面试重标定前，程序不会声称得到 g·mm、配重质量或最终配重角。

正式双面校正需在固定安装、转速和增益条件下依次测量：无试重基线、左校正面已知试重、右校正面已知试重。由响应变化建立 2×2 复数影响系数矩阵，再解左右校正矢量，并用复测验证残余量。转子、装夹、传感器位置、前端增益或转速工况变化后应重新标定。

## 运行和测试

在 PyCharm 打开 `/Users/apple/PycharmProjects/dynamic_balancing_test`，选择 `.venv/bin/python`，运行根目录 `main.py`：

```bash
cd /Users/apple/PycharmProjects/dynamic_balancing_test
.venv/bin/python main.py
```

目标电脑需安装 LabJack LJM 驱动。Windows 上使用 IEPE 时还需安装 NI-DAQmx、在 NI MAX 中确认 cDAQ-9174/NI-9234 自检通过，并安装 `nidaqmx` Python 包。`config/devices.json` 可设置 NI 模块名、ai0/ai1 及混合采样率；默认使用 NI-9234 原生的 25.6 kS/s，避免把 30 kS/s 强制提升到 51.2 kS/s 后超过 LabJack 三通道采集预算。若默认模块别名与 NI MAX 不一致，只有一个 NI-9234 时程序会自动识别。LabJack 序列号默认 `AUTO`。`config/process.json` 可修改 PPR、候选 1X 范围、分析窗、转速波动及信噪比门限。

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m compileall -q main.py config drivers models services ui utils workers tests
.venv/bin/python -m pip check
```

自动化测试使用受控的数值夹具验证算法，不会在生产程序中提供或启用仿真设备。
